# Lelelilo Unknown

The built game, served by GitHub Pages: https://lelelilo-studios.github.io/lelelilo-unknown-web/

A phone game made one step at a time. The newest iteration is at the root; each one stays under `v/NN/`.
It needs a browser with WebGPU (Chrome on Android, Safari 26+ on iPhone).

By [lelelilo.com](https://lelelilo.com/?ref=lelelilo-unknown).
